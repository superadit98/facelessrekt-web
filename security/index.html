Severity

Severity follows impact, not novelty. A boring bug that leaks other people's personal data beats a clever one that prints a debug string.

LevelTypical impact

How I report

  • Private report to the vendor or program first. Nothing public before a fix.
  • 90 days is the default window, longer if the vendor is actively working on it.
  • I only take what is needed to prove impact. One record is enough to show exposure, so I stop there.
  • Personal data found during testing is never stored, shared or kept. Reports describe type and count, never content.
  • No persistence, no lateral movement, no denial of service, no social engineering of staff.
  • If a vendor goes quiet, escalation goes through the program or a CERT, not a public drop.
