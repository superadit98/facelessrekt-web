Disclosure policy

  • Report privately to the vendor or program first. No public details before a fix.
  • Coordinated disclosure: 90 days is the default window, extendable if the vendor is actively working on it.
  • No exploitation beyond what is needed to prove impact. No access to other users' data beyond a single proof, no persistence, no lateral movement.
  • Findings are published only after remediation, or with explicit written permission, and always redacted.
  • If a vendor is unresponsive, escalation goes through the program or CERT, not through a public drop.

Report a vulnerability

developers@facelessrekt.com

Encrypt sensitive details if you prefer; ask for a key first. Include the asset, a reproduction sketch, observed impact, and whether you intend to publish.
